# Sources, units, and rights

The atlas derives its tables and figures from [SWBLI Physics Bench v0.1.0rc1](https://github.com/hengyuhang61-creator/swbli-physics-bench/tree/d1f488778142859aff05bca5d766a7da4f9afa7d), commit `d1f488778142859aff05bca5d766a7da4f9afa7d`. Its [pinned input manifest](https://github.com/hengyuhang61-creator/swbli-physics-bench/blob/d1f488778142859aff05bca5d766a7da4f9afa7d/sources/inputs.json) records upstream files, byte counts and SHA-256 hashes. Original archives, solver exports, grids and reports are linked and retrieved at replay time. This repository does not redistribute those source files.

| View | Data and processing |
| --- | --- |
| Mach 2.05 ramp | [Stanford experiment in the NASA/TMR catalog](https://tmbwg.github.io/turbmodels/Other_exp_Data/sbliM2.05_exp.html). The public SU2 study publishes the [PIV extract and computed columns](https://github.com/ofirnirr/SU2-SWBLI-Mach-2-RANS-Validation/tree/2b2be8c4e982af6e97542237aeaaf9da615707bd). The figure averages U / 532 m/s into 1 mm × 1 mm bins at z = 21 mm and leaves empty bins blank. The archived experiment quotes a nominal 530 m/s. The interface uses derived common-support error metrics. The Stanford contributed data and pinned SU2 files do not carry a specified redistribution license in the inspected sources. |
| Mach 2.5 cone | [NASA TMR TCFDVE case](https://tmbwg.github.io/turbmodels/sbli_tcfdve.html). The field view shows sampled experimental PIV columns at the ten archived x locations. Uref = 589.1 m/s. The browser sliders use derived FUN3D errors at x = 482.60 mm. TMBWG's site repository lists CC0-1.0. Credit remains with the underlying experiments and published solver work. |
| Mach 3 HMVE | [NASA/TM–20250008885](https://ntrs.nasa.gov/citations/20250008885) and its attachment. Values use the archived U₁ basis. Plots show measured samples using nominal probe x (inches converted to mm) and radial y in mm. Interactive values use published band means. No CFD result is shown for this comparison. |

The 2D maps share a display scale of 0–1.15 in normalized axial velocity, with colorbar ends denoting values outside that range. Case-specific reference velocities apply as stated in each caption. Sparse fields use measurement squares and leave the space between stations unfilled. No generated images or interpolated time frames are used. See the bench's [case conditions and rights](https://github.com/hengyuhang61-creator/swbli-physics-bench/blob/d1f488778142859aff05bca5d766a7da4f9afa7d/cases/README.md) and [physics notes](https://github.com/hengyuhang61-creator/swbli-physics-bench/blob/d1f488778142859aff05bca5d766a7da4f9afa7d/reports/PHYSICS_EXPERIMENTS.md) for model identities and experimental limits.
