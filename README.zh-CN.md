# MachAtlas

**看见超声速飞行背后的物理。**

**v0.2.0 新增** [原生 SU2 科研入口](https://hengyuhang61-creator.github.io/machatlas/research.html)，包含 Mach 5 网格与壁温对照、Mach 2.05 入口核验及完整复算说明。

[打开公开图鉴](https://hengyuhang61-creator.github.io/machatlas/) · [版本发布](https://github.com/hengyuhang61-creator/machatlas/releases/latest) · [反馈](https://github.com/hengyuhang61-creator/machatlas/issues/new)

- **Mach 2.05 斜坡**。Stanford PIV 与已公开的 SU2 结果，在相同测量位置切换误差指标。
- **Mach 2.5 轴对称锥**。NASA PIV 与已公开的 RANS 结果，移动同宽的径向窗口，观察 FUN3D 模型比较怎么变。
- **Mach 3 HMVE**。两组 NASA PIV 实验，在 21 个对齐测站比较两个径向带的速度均值。

图像来自真实实验数据的后处理。第三个案例由两组实验直接比较。复算命令、单位及证据边界见[英文说明](README.md)和[来源](SOURCES.md)。
