# Mach 5 SWBLI: Turbulence-Model Discrepancy and Numerical Credibility

**Question.** Why does plain SST-2003m produce an approximately 21–24 mm separation bubble in the current native SU2 study while the archived SU2 curve spans 8.27 mm?

**Result on the locked coarse mesh.** With the same adiabatic settings and the same initial checkpoint, stock SU2 8.6.0 and 7.4.0 settle at 23.57 and 7.92 mm, respectively. A separate change from adiabatic walls to 300 K at fixed SU2 8.6.0 shortens the bubble to 18.93 mm. This isolates a large version-dependent effect in the present comparison. The old executable yields a bubble length within 0.35 mm of the historical value on the present mesh. This comparison addresses length and leaves full trace agreement and historical run provenance open.

[Interactive comparison](https://hengyuhang61-creator.github.io/machatlas/research.html#discrepancy) · [Frozen contract](DISCREPANCY-CONTRACT.md) · [Native evidence archive](https://github.com/hengyuhang61-creator/machatlas/releases/tag/v0.2.1)

The version effect is dominated by the strain input to the SST eddy-viscosity limiter. In a separate controlled source experiment on Linux, stock SU2 8.6.0 and a build differing in one line used the same binary restart, mesh, inputs and compiler settings. Replacing the resolved strain magnitude by the historical floor changes the separation length from 23.56 mm to 7.13 mm (16.42 mm change). The same-version effect exceeds the 15.64 mm observed release-pair effect in this test, and the controlled variant remains 0.79 mm shorter than the official v7.4.0 result. The archive does not isolate individual contributions to that residual.

## Controlled contrasts

Each coarse branch starts with the same verified v0.2.0 SST restart at cumulative step 4,600 (SHA-256 `1aa04959915b6261b8efe15a1ebc9df50ad5dd1e9eb8cc02a5f4884b5907567f`) and the same 37,275-cell mesh (`942a5a493d4351028125ad0c2787a5e70e7f596672c3af3a8f9b45a7166e9989`). Both binary-version branches use one thread. Both thermal branches use three threads. The starting version-pair configurations are byte-identical. The thermal branches differ only in the two wall thermal markers, with both top and bottom set to zero heat flux or both fixed at 300 K. The 10 mm slip extension and the Roe/MUSCL flow and first-order scalar transport are unchanged. The prescribed inlet is 68.3333 K, 4,006.88 Pa and 828.58 m/s with nominal Mach 5. All primary pairs use plain `V2003m`, without a Wilcox correction. The historical published 7.4.0 deck used different CFL adaptation, linear error tolerance and Newton–Krylov settings. The bridge fixes these inputs to the v8.6.0 study settings across both executables.

## One-line source experiment

The limiter is μₜ = ρa₁k / max(a₁ω, S × F₂) for SST-2003m. When the strain limb is active, it lowers the permissible eddy viscosity at a fixed state. For the paired run, the change from the modern flow-node strain value to 10⁻¹² leaves all other v8.6.0 terms intact. Both Linux runs used the identical coarse mesh, two threads, adiabatic walls and the same 3,600-iteration stock restart. The stock branch met the gate at 6,300 cumulative iterations with separation at 321.95 mm and reattachment at 345.51 mm. The floor branch was continued from its verified 9,900-iteration save and met the same gate at 10,800, with crossings at 335.67 and 342.81 mm. The last three floor lengths span 0.0141 mm. The continuation used the same GCC version and source patch on a different runner CPU. The rebuilt executable has a different fingerprint. The original same-host experiment already gave a 16.42 mm effect before the continuation, and the additional checked interval changes that effect by about 0.004 mm. This direct intervention establishes the limiter-input effect on the chosen mesh and boundary conditions.

## Implementation checks

- **SA names.** Both official SU2 SA configs set `WITHFT2, NEGATIVE`. This identifies SA-neg with the fₜ₂ term, consistent with the SU2 V&V label. The MOSE reference solver's own SA run uses SA-noft2. Wind-US deck `turbulence spalart` identifies a family label and does not establish identical negative-state handling, fₜ₂, diffusion or freestream treatment. The archived SU2 SA span of 5.51 mm versus the current 4.59–5.10 mm is a scalar consistency check. [SU2 V&V](https://su2code.github.io/vandv/swbli/) · [MOSE methods](https://open-hydra.github.io/MOSE/vv/2D-swbli/) · [NASA TMR model definitions](https://tmbwg.github.io/turbmodels/spalart.html)
- **SST version.** SST-2003m uses the strain magnitude in its eddy-viscosity limit. SU2 7.4 obtains it from the turbulence node object whose inherited getter returns zero, then applies a floor of 10⁻¹². The denominator therefore effectively lacks the S × F₂ limiter where `a1*omega` dominates the floored value. SU2 8.6 reads actual strain from the flow-node object. Upstream fixed this lookup in PR #2453. The release contrast bundles other changes, including the wall condition, cross-diffusion discretization and scalar numerical kernels. [7.4 source](https://github.com/su2code/SU2/blob/v7.4.0/SU2_CFD/src/solvers/CTurbSSTSolver.cpp#L228-L243) · [8.6 source](https://github.com/su2code/SU2/blob/v8.6.0/SU2_CFD/src/solvers/CTurbSSTSolver.cpp#L239-L256) · [PR #2453](https://github.com/su2code/SU2/pull/2453) · [PR #2533](https://github.com/su2code/SU2/pull/2533) · [PR #2878](https://github.com/su2code/SU2/pull/2878)
- **Wall ω.** Both smooth-wall versions use the expression 60ν/(β₁d²). Version 7.4 takes ν and the node distance from the normal-neighbor path. Version 8.6 uses wall-node ν and a nearest-neighbor distance. Its isothermal turbulence boundary calls the heat-flux turbulence wall path, so changing wall temperature can also change the viscosity in this expression. MOSE's verified OpenFOAM-matched setting uses 80νw/yc² at a cell face. Vertex versus face placement and distance definitions matter. [SU2 PR #2392](https://github.com/su2code/SU2/pull/2392) · [MOSE wall study](https://open-hydra.github.io/MOSE/vv/2D-swbli/)
- **Wilcox and wall heat.** The v8.6 shipped case deck adds `COMPRESSIBILITY-WILCOX`; the v7.4 deck and this matched comparison use plain SST-2003m. Wilcox modifies the turbulence equations and is separate from imposing a 300 K wall. The previously released Wilcox run shows 7.20 mm of early separation drift between saved states at low mass error. It does not constrain the settled plain-SST gap. SU2 issue #2834 concerns Sarkar with its correction active. It does not verify a fault in the present plain SST. [Wilcox checkpoint replay](https://hengyuhang61-creator.github.io/solverfails/mach5-drift.html) · [Issue #2834](https://github.com/su2code/SU2/issues/2834)
- **Mach 2.05 geometry.** Stanford measured a finite-span, low-aspect-ratio tunnel with a fully spanning top-wall 20° ramp and four spanwise measurement planes. The 2-D prototype uses a 45 mm-high, −40 to 90 mm test section and a synthetic uniform-inlet development extension back to −430 mm. An upstream PIV match is a screen for development at the compared planes. It does not reconstruct the real upstream geometry, side-wall interactions or a spanwise average. The 52 original run configs contain 50 adiabatic stages and two 300 K stages. Both 300 K stages belong to the prior coarse Mach 5 SA control. The Mach 2.05 matrix used zero heat flux, with no isothermal branch. [Existing transfer study](M205_RESULTS.md) · [Stanford/NASA TMR](https://tmbwg.github.io/turbmodels/Other_exp_Data/sbliM2.05_exp.html)

## Numerical and experimental bounds

Cf,x is signed streamwise wall shear normalized by freestream dynamic pressure. Cp is the pressure difference from freestream, normalized by freestream dynamic pressure. The analysis interpolates between adjacent Cf samples of opposite sign in 300–450 mm. The archive supplies the exact crossing brackets, signed traces, minimum Cf, Cp at 360 mm, drag, y⁺, residual histories and both native and field-reconstructed open-boundary mass checks. For v7.4, field velocity is reconstructed from conservative momentum divided by density. A shallow mass imbalance does not measure wall shear accuracy. Reported total-enthalpy flux is advective only and excludes wall heat, viscous work and conduction. The ω residual remains materially higher than the flow residual after the wall-QoI gate.

The [machine-readable summary](discrepancy-results.json) records the numerical checks and reference metrics. The existing modern 23.56, 23.14 and 21.17 mm SST sequence spans 2.39 mm across 37,275, 75,639 and 145,765 cells. This is substantially smaller than the 15.64 mm matched coarse version effect. The three-grid sequence and its iteration errors do not establish an asymptotic range or a GCI. A supplementary v7.4.0 replay on the 75,639-cell mesh reached 8.09 mm at its resource cap, versus 23.14 mm in the previously saved v8.6.0 medium-grid result. Its latest span was small but still trended beyond the strict direction check. It corroborates the direction of the change but is excluded from the settled pair. On the common 0.320–0.400 m reference points, the mean absolute Cf error against the historical SU2 trace drops from 0.001341 (current) to 0.00008094 (old). Against the DLR samples it is 0.001030 and 0.000786, respectively. These error statistics do not remove reference or boundary-condition differences.

The Schülein curve hosted by MOSE gives 333.74 and 345.83 mm, with sampled brackets 330.63–333.81 mm and 343.05–345.89 mm, respectively. These are station-spacing limits. Statistical and spatial experimental uncertainty are not inferred from them. The archived Wind-US SST span is 17.09 mm and its published deck specifies 540 °R (300 K) and a different grid and numerical scheme. The temperature match alone does not harmonize the codes. The historical SU2 result spans 8.27 mm under the same crossing definition. The exact original mesh bytes and restart history were not established. The DLR archival record documents the experiment. The NASA package lists a wall-friction comparison; no matched experimental Cp curve was used here. NASA restricts sharing the experimental velocity profiles for this case. [DLR bibliography](https://elib.dlr.de/21724/) · [NASA Wind-US study and inputs](https://www.grc.nasa.gov/WWW/wind/valid/m5swbli/study02/m5swbli2.html) · [Reference comparisons](m5-reference-comparison.json)

## Replay

1. Fetch the pinned SU2 V&V geometry and generate the coarse mesh as in [REPRODUCE.md](REPRODUCE.md). The archive gives the original meshes' hashes and the saved coarse and medium restart inputs. On a regenerated mesh, verify the hash or verify point ordering and restart compatibility before using an archived binary restart. A cold replay with its own shared parent is also supported.
2. Obtain the official [7.4.0 serial](https://github.com/su2code/SU2/releases/tag/v7.4.0) and [8.6.0 OpenMP](https://github.com/su2code/SU2/releases/tag/v8.6.0) builds as appropriate. Preserve each case configuration and set the stage input to the previous verified restart. Reuse the supplied `sst-v2003m.cfg` from the pinned v8.6.0 config by changing only `SST_OPTIONS` to `V2003m`. Start separate branches with `run_native.py`, then `continue_pair.py` until the frozen gate passes or report the resource cap. Execution JSON binds the run inputs and binary hashes to the original logs.
3. To rerender the comparison, run `python research/make_discrepancy.py <evidence-layout> site research/m5-reference-comparison.json` with the chain JSON and terminal stage directories at the same root. The renderer interpolates steady native fields only. The axes note the vertical scale.
4. [Same-version one-line experiment workflow and archived logs](https://github.com/hengyuhang61-creator/machatlas/actions/runs/45486012820). Rebuild both Linux binaries with the same toolchain and mesh, then resume both from the same stock checkpoint. The only source change fixes the limiter input to the historical 10⁻¹² floor.

**Disposition.** This study targets a solver discrepancy. It reports numerical evidence and a scope-limited causal test. A calibrated physical uncertainty budget and independent experimental validation remain open.
