# Mach 2.05 pilot gate

Frozen before running the 3 mm pilot on 2026-11-24 MSK. The 5 mm case is an available separate geometry.

- The 20° fully spanning ramp and 3 / 5 mm heights come from the NASA TMR Stanford archive. A 45 mm-high section from x = −40 to 90 mm is the existing public 2-D computational idealization. Record the gap to the finite-width experiment.
- Use Mach 2.05, published stagnation conditions 303 K and 255.3 kPa, ideal air gamma 1.4, R = 287.058 J/(kg·K), giving 164.629 K, 30.184 kPa and 527.298 m/s at the uniform inlet. Document that the prior public computational example specifies 4,006.88 Pa and 167.58 K. That is a substantially different nominal Reynolds number; do not infer it was the executed input.
- Use 12,288 structured quadrilaterals, SA-neg, adiabatic no-slip walls, Roe + limited MUSCL. Adiabatic is a modeling choice. Freeze the numerical controls before startup.
- Read the published near-centreplane 3 mm, z = 21 mm upstream PIV profiles at x = −30 and −10 mm. Compare only the measured supported y values, with no clamping/extrapolation. Require an upstream common-support mean absolute error ≤ 5% of reference 530 m/s at both planes before expanding this uniform-inlet branch. This deliberately lenient screen is above the reported representative U uncertainty. It is a development criterion, not a universal validation threshold.
- A failed profile gate requires an inlet/precursor correction before the remaining candidate simulations. Positive fields, mass balance and a negative data-qualification result can coexist.
The first pilot failed both PIV profiles and had bottom y+ p95 = 10.55. In the follow-up, vary the wall-normal mapping from tanh factor 6 to 9, holding streamwise grid, cells, geometry, closure and boundary conditions fixed. Keep the originally frozen profile gate.
The repacked run still failed. One development control extends only the upstream segment from x=-40 mm to x=-430 mm. The flat-plate estimate delta=0.37*x*Re_x^(-1/5) gives the order of 0.4 m for a 5.4 mm boundary layer at the stated unit Reynolds number. Keep the -40..90 mm grid identical and the same wall clustering. This is a 2-D precursor experiment, not documented actual tunnel geometry. No PIV gate is changed.
Fine 5 mm SA/SST completed the first 1800 iterations but exceeded the 0.1% mass gate at 0.1013378% and 0.1136069%. Preserve those native checkpoints. Reopen only for one same-grid continuation of 600 iterations from each and compare with 300 more only if the original numerical and upstream gates pass. The mesh, BCs and numerical schemes are unchanged. No threshold shift.
